# Protótipo · ASA Beach Tennis

Protótipo de site e sistema feito pela Turma Cheia para apresentar à ASA Beach Tennis (Aracaju). Não é o site oficial da arena.

Turmas, alunos, vagas, movimento e números da gestão são de exemplo.

- `index.html`: apresentação
- `site.html`: site
- `app.html`: app do jogador
- `professor.html`: painel do professor
- `gestao.html`: painel da gestão
